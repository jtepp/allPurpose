# Time Trials support page

This static page is intended for the App Store Connect Support URL. Deploy the contents of this folder at the URL you choose (for example, `/support/`). The page uses the app's rounded iOS icon as `icon.png`.

The support email is set to `jtepp+site@icloud.com`, the public contact address currently used by the portfolio site. Update `supportEmail` in `TimeTrialsAppStoreSupport.jsx` if a dedicated support inbox is preferred.
