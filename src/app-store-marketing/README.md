Marketing page for App Store Connect `Marketing URL`.

Files:

- index.html — entry (React via CDN)
- app.jsx — small React landing page
- styles.css — page styles
- hero.svg, logo.svg — SVG assets

Deployment:

- Copy `app-store-marketing` to your host, e.g. `https://yourdomain.com/app/`.
- Set App Store Connect `Marketing URL` to that published URL, e.g. `https://yourdomain.com/app/`.

Replace `https://apps.apple.com/app/idYOUR_APP_ID` in `app.jsx` with your actual App Store link.
