# Time Trials marketing page

This static page is intended for the App Store Connect Marketing URL. Deploy this folder at the URL you choose (for example, `/app/`). It includes the Time Trials rounded iOS app icon as `icon.png`.

The page describes features present in the project and says the iPhone app is in development. It intentionally has no App Store download link until a real listing URL is available. The support link points to `/support/`; adjust it if your published support page uses another path.
